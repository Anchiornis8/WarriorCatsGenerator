# WarriorCatsGenerator
This is a Generator for making cats

## IMPORTANT!!!
This game has no permission or contact with the Erin Hunter Team. It is not offizial. Please use it for fun.

## How to use it
1) Download the files
2) make a directory called WarriorCatsRGP to but the files in
3) put a "Cats" directory for the cats into the directory WarriorCatsRGP (it must be called Cats)
4) run it with bash WarriorCatsRGP.sh
